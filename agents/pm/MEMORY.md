# Morgan's Memory — Product Manager

## Owner Preferences & Decisions
- Campaign types: Trunk Show, End of Year, Mid Year, Custom
- AI suggestions should be based on verification history and benefit usage data

## Core Differentiator — Verified Benefit Amounts in Messages
- When a patient is verified, their hard dollar amounts are stored (frame allowance, contacts allowance, etc.)
- Campaign messages use merge tags to pull those verified amounts per patient at send time
- Result: every patient gets a personalized SMS like "You have $150 for frames and $130 for contacts"
- No competitor does this automatically — this is the #1 selling point
