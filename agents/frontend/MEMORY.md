## Design Preferences
- NO emojis in the UI — keep everything professional and clean
- Campaign cards should look polished and text/icon based, not emoji based
- Tone: clinical, trustworthy, medical SaaS — not consumer/playful

## Key Product Feature — Merge Tags
- Hard dollar amounts from verification must be usable in campaign messages
- Merge tags: {{first_name}}, {{carrier}}, {{frame_allowance}}, {{contacts_allowance}}, {{lens_benefit}}, {{benefit_expiry}}
- Message builder shows clickable tag buttons + live preview with real patient data substituted in
- This is the #1 differentiator — every campaign message is personalized with verified benefit amounts
